EInstalling Expert Widget

There are two ways to get the widget onto a Windows PC. Pick one, follow its column, and both end in the same place: the round E button on your screen, waiting for your CV.

  • You do this
  • Happens on your PC
  • Downloads from the internet
  • Check or choice

Which way is for you?

Way A

Use the installer

For anyone. No programming tools needed.

  • You need the file Expert Widget Setup 0.1.0.exe
  • About 2 minutes
Go to Way A ↓
Way B

Build it from the code

For people who want to change the code or make their own installer.

  • You need Node.js, Git and access to the GitHub repository
  • About 10 to 15 minutes the first time
Go to Way B ↓

First start

The same for both ways.

this PC1The round E button appearsAnd a teal E in the tray at the bottom right (click the small ^ if you don't see it). The widget creates Documents\ExpertWidget\ with a CV\ folder, config.json and employers.json.
you2Put your CV in the CV folderExactly one file: PDF, Word (.docx) or text, in German or English. A scanned PDF (a picture of text) cannot be read. 
Documents\ExpertWidget\CV\
you3Double-click the E, then press RefreshThe first Refresh takes up to half a minute.
Do you see your domain mix, employers and news?
Yes
Done. Press Refresh whenever you want fresh news.
No
The widget shows a short message saying what is wrong. Look it up in the table below.

If something goes wrong

You seeDo this
node or git is not recognisedInstall it (Way B, step 1), then close and reopen PowerShell so it picks up the new program.
git clone says "Repository not found"The repository is private. Ask the owner for access and accept the GitHub invite.
npm install failsCheck node -v shows 20 or higher. On a company network, a proxy or firewall may block downloads.
"Downloading Electron" on the first startLet it finish once. It only happens the first time.
"No CV found" or "more than one CV"Put exactly one file into Documents\ExpertWidget\CV\ and press Refresh.
"Could not read" your CVClose it in Word if it is open. If it is a scanned PDF, save a text-based PDF or a .docx instead.
"One source could not be loaded"Nothing to do. That one news site was busy or unreachable; the others still load, and it is tried again next time.
The widget disappearedIt is still running. Press Ctrl+Alt+E, or click the teal E in the tray.
News stays in GermanThe translation model did not download. Run npm run compile (Way B) or reinstall (Way A).

Your CV stays on your PC. The widget only sends fixed web addresses and keyword searches from config.json to the internet.
